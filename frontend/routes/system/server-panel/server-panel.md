## DESCRIPTION::ES
Panel de servidor, exclusivo SaaS. Vista Dashboard: gráficos de las últimas 4 horas (CPU y memoria del host, de cada servicio —Backend, ScyllaDB, GenixSearch, Server Utils— y de la red) leídos de la tabla `server_metrics` que escribe server_utils cada 5 segundos. Vista Memory: inspeccionar el uso de heap y memoria del proceso backend.

## DESCRIPTION::EN
Server panel, SaaS only. Dashboard view: charts of the last 4 hours (host CPU and memory, per-service CPU and memory for Backend, ScyllaDB, GenixSearch and Server Utils, plus network) read from the `server_metrics` table that server_utils writes every 5 seconds. Memory view: inspect heap and memory usage of the backend process.
